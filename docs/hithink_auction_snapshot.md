# 全A集合竞价快照

`market.hithink_auction_snapshot` 保存同花顺集合竞价接口返回的原始事实，不做派生或重算。

## 采集时间

交易日固定采集11次：

```text
09:15:00、09:16:00、09:17:00、09:18:00、09:19:00、09:20:00
09:21:00、09:22:00、09:23:00、09:24:00、09:25:00
```

该任务由现有 `HithinkSnapshotCollector` 常驻服务中的独立执行通道负责，不另建 Windows 计划任务，也不加08秒或0.5—1.5秒延迟。09:15—09:24使用接口实时阶段，09:25使用终态。

接口单次最多接收100只股票。任务在每个整数分钟将全A代码拆批并同时发起请求，使同一张快照的各批来源时间尽量集中。代码范围在08:50交易日确认后先从全A接口取得一次，09:13:50再次申请并以这次名单为准；09:13:50申请失败时回退到上一交易日收盘的全A代码清单。

错过计划时间超过2秒时不补采，避免把稍后数据冒充计划时点数据。每次写入继续使用与主时间轴一致的 `collection_id`：09:15对应001，09:25对应011。
