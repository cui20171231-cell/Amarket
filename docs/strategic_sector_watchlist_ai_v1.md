# AI战略主线V1映射与维护规则

`market.strategic_sector_watchlist` 是配置/知识层长期名单，不是行情采集表或盘中派生表。
行情强弱、候选排名和成交份额不写入本表。名单只通过人工、AI研究或产业研究变更，不能按短期行情自动增删。

## 历史维护

当前有效记录使用 `is_active=1`、`effective_to=NULL`。移出名单时不删除，写入新版本，设置
`is_active=0` 和实际 `effective_to`。历史查询使用：

```text
effective_from <= 查询日期
并且 effective_to为空或effective_to >= 查询日期
```

重新启用同一板块、同一战略主题且需要保留多个不连续有效区间时，应先评估是否把
`effective_from` 加入排序键；当前V1唯一语义按用户指定的“板块类型+板块代码+战略主题”执行。
