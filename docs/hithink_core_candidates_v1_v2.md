# 核心板块与核心个股候选：V1正式口径和V2升级边界

## 版本边界

当前正式版本为 `V1`。两张实体表都写入 `candidate_model_version='V1'`，并且完全不包含、
不读取、也不推算总股本、流通股本、总市值、流通市值、真实换手率或成交额/流通市值。

V1的个股“成交承载代理”只表示绝对成交额和一分钟成交额在全市场中的相对位置，不能解释成
真实市值容量。数据库不保存主线、龙头、买点、卖点、大中小市值核心或容量龙头标签。

## 核心板块候选V1

来源为板块资金迁移表和板块状态。核心候选只允许概念和行业参与，两类独立排名。
V1候选上限为概念20、行业15；上限是参数，不是必须凑满的数量。
风格仍保留在资金迁移和市场风格观察中，但不参与核心板块、主线竞争或核心个股加分。
但只有达到最低条件才保存。

七项命中继续负责解释候选原因，规则保持不变：

```text
价格强度：累计涨幅位于同类前15%且为正，或一分钟涨幅位于前10%且为正
板块广度：上涨覆盖率>=60%，或最近一段上升>=10个百分点
累计成交关注度：累计成交份额排名位于同类前10%
成交关注加速：累计份额上升且排名不降，或一分钟份额上升且排名上升
涨停结构：至少1只涨停，且涨停数不低于炸板数
新高结构：新高率>=10%，或最近一段提高>=5个百分点
持续性：本时段最近3个目标中至少2次达到初筛条件
```

```text
candidate_hit_count = 七项命中数量
最低条件仍按原二值命中分计算：原命中分>=35、至少2项命中，且价格/成交份额/涨停/新高至少命中一项
```

`candidate_score_v1` 改为0至100的连续排序分。每个维度由“命中奖励+同类相对强度”组成：

```text
价格强度20 = 命中8 + 累计/一分钟涨幅较强者的同类百分位×12
板块广度15 = 命中6 + 上涨覆盖率/覆盖率改善较强者的同类百分位×9
成交关注度20 = 命中8 + 累计/一分钟成交份额较强者的同类百分位×12
成交关注加速15 = 命中6 + 两种成交份额正变化较强者的同类百分位×9
涨停结构10 = 命中4 + “涨停数-炸板数”的同类百分位×6
新高结构10 = 命中4 + 新高率/新高率改善较强者的同类百分位×6
持续性10 = 命中4 + 最近3/5节点命中比例较强者×6
```

相对强度只在 `concept`、`industry` 各自内部计算。没有数据或方向不为正时，
对应的正向强度记0；相同原始事实允许得到相同的维度分，不通过板块代码人为制造差异。

`candidate_reason_mask` 位定义依次为1、2、4、8、16、32、64。连续分只用于排序，不能解释为
主线概率。持续性按上午和下午分别计算，13:00重新开始。

## 核心个股候选V1

八项命中及分值：

```text
价格强度 20：涨幅>=3%且位于市场前10%，或一分钟涨幅>=1%且位于前5%
绝对成交承载代理 20：累计成交额位于全市场前3%
成交加速 15：一分钟成交额位于前3%且为正，或一分钟成交增长>=50%
新高 10：当前创盘中新高
涨停/炸板强势表达 15：当前涨停或炸板
核心板块关联 10：属于至少一个当前核心板块候选
板块内部地位 5：在最强所属核心板块中，成交额/一分钟成交额/涨幅任一排名前5
持续性 5：本时段最近3个目标中至少2次达到初筛条件
```

```text
candidate_score_v1 = 八项命中分值之和
最低条件：分数>=35、至少2项命中，且价格/成交/加速/新高/涨停炸板至少命中一项
每节点最多50只，不强制凑满
```

因此只属于很多强板块、但自身价格和成交表达都弱的股票无法入选。`candidate_reason_mask` 位定义
依次为1、2、4、8、16、32、64、128。上午、下午持续性分别统计。

## V2升级清单

未来基础信息接口恢复后，建立带 `effective_from/effective_to` 的证券基础信息历史，再对原表执行
`ALTER TABLE ADD COLUMN`，不新建V2候选表。计划增加：

```text
total_shares
float_shares
total_market_cap
float_market_cap
float_market_cap_rank_market
turnover_to_float_cap_pct
turnover_to_float_cap_rank_market
turnover_rate_pct
```

计算口径：总市值=最新价×总股本；流通市值=最新价×流通股本；成交额占流通市值比例=
成交额/流通市值。只有确认成交量单位和股数口径后才计算真实换手率。V2继续保留V1全部证据，
新记录写 `candidate_model_version='V2'`，历史V1解释不变。

## 执行边界

本轮只建立表、历史回算和验收文件，尚未接入常驻派生程序。固定顺序为：前三张状态表完成，
再生成核心板块候选，最后生成核心个股候选。
