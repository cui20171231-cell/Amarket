# N100 服务器第一阶段优化计划

建立时间：2026-08-29 14:13

执行状态：已完成，2026-08-29 14:23，未重启系统。

## 目标

这台机器用于行情采集、ClickHouse 存储、ChatGPT 访问、收盘报告和行情分析。第一阶段只清理与这些用途无关的常驻程序。

## 本阶段改动

1. 卸载 Intel(R) Computing Improvement Program，移除使用情况上报、能耗统计和相关采集程序。
2. 停止并禁止自动启动英特尔显卡控制面板与性能监控服务；保留 Intel UHD 核心显卡驱动、HDCP 服务和设备管理组件。
3. 停止 Windows 小组件和跨设备继续程序。相关系统策略在改动前已经是关闭状态，不需要再改注册表。
4. 删除 Chrome 和 Edge 的开机自动启动项，不卸载浏览器。

## 明确不改的内容

- 不停止 Docker、WSL 和 ClickHouse。
- 不停止行情采集、日K、板块同步、网关和隧道。
- 不停止 Tailscale、ChatGPT/Codex 进程和 Windows Defender。
- 不卸载 Intel UHD 核心显卡驱动。
- 不修改数据库、表结构和任何行情数据。

## 回退方法

- Chrome 启动项恢复为：`"C:\Program Files\Google\Chrome\Application\chrome.exe" --no-startup-window /prefetch:5`
- Edge 启动项恢复为：`"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --win-session-start`
- 英特尔显卡附加服务可恢复为自动启动后重新启动。
- Intel(R) Computing Improvement Program 如需恢复，需从英特尔安装程序重新安装。
- Windows 小组件和跨设备功能的软件包保留，本阶段只停止当前进程。

## 验收标准

- ClickHouse 容器仍为健康状态。
- 数据库 19 张表可正常查询。
- 采集、网关、隧道和托盘计划任务状态正常。
- Tailscale 和 ChatGPT/Codex 连接保持运行。
- Intel UHD 显卡设备状态仍为正常。
